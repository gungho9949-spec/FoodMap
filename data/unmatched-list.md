# 미매칭 맛집 목록 (상호명 미확인)

나무위키 "맛있는 녀석들/방영 목록" 각주에서 지역+음식 특징은 확인되지만,
정확한 상호명이 나오지 않아 카카오 로컬 API 검색을 시도하지 않은 항목들.
추후 상호명을 확인하면 `data/curated-food.js`로 옮겨서 카카오 검색 매칭 가능.

- **주은** - 미슐랭 1스타 전통 한식 다이닝 (검색 시 동명의 감자탕집만 나와 실제 매장과 다름)
- **호빈** - 후덕죽 셰프가 운영하는 레스토랑 (동명의 칵테일바/치킨집 등과 혼동되어 특정 불가)
- **오리지널넘버스** - 흑백요리사2 '삐딱한 천재' 출신 셰프의 레스토랑 (카카오 검색 결과 없음)

- **쌤쌤쌤** - 양식 레스토랑. 용산/광화문/롯데월드몰 등 여러 지점이 있어 방문 지점 특정 불가

- **별봄차이나** - 일산 소재 짬뽕집으로 추정 (카카오 검색 결과 없음)
- **류진** - 지로라멘 전문점, 토핑 무료 추가로 유명 (카카오 검색 결과 없음)

## 출처: 쯔양 (팬 제작 지도 "쯔동여지도" tzudong.app, 총 530개 중 일부만 확인)

- **문터골연가** - 쯔동여지도 인기 TOP5 맛집 중 하나(경기 김포시 하성면). 카카오 검색 시 정확히 일치하는 주소가 나오지만 업종이 "숙박(펜션)"으로 분류되어 있어 식당인지 숙박+식사 겸업인지 확인이 필요해 보류.
